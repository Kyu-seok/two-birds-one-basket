# Hawk chaser instead of auto-scroll

Players must control their own movement, so the world never scrolls on its own. Without pressure, though, the best strategy in an endless climb is to creep slowly and safely. The Hawk supplies that pressure: it climbs at a pace that rises with Height, and catches up when far behind so it stays about 8 seconds back and there is never a safe lead to rest in. Timing hazards in higher Pieces add further pressure.

## Considered Options

- **Auto-scroll:** rejected, because it takes control away from the players.
- **Gravity alone as the clock (hovering costs voice):** rejected as too weak; a strong-voiced pair could still creep.
- **Rising fog or water:** a faceless version of the Hawk; the Hawk was chosen because it fits the theme (it wants the Egg).
