# Timed hazards instead of a chaser

The game became a side-scrolling voice platformer, where you move only while making sound. We dropped the Hawk and added no auto-scroll. The challenge is meant to be skill, not stamina: players can always go silent to breathe or plan. Pressure comes only from timed hazards, such as crumbling or moving platforms, that punish waiting at particular spots. This supersedes ADR 0004.

## Considered Options

- **Keep a chaser (the Hawk):** rejected, because constant pressure forces non-stop voice and turns endurance into the main skill.
- **Auto-scroll:** rejected for the same reason, and because it takes movement out of the players' control.
